# Security Policy

## Supported Versions

Scriptorium is a pre-1.0 project. As such, only the latest commit on the `main` branch is supported and eligible for security patches. There are currently no separate maintained release branches.

If you are using an older version, we strongly recommend updating to the latest `main` branch.

## Reporting a Vulnerability

**Do not open a public GitHub issue with exploit details, credentials, or other sensitive information.**

### Primary Channel
Use GitHub's private vulnerability reporting feature:
1. Navigate to the [Scriptorium repository Security tab](https://github.com/AmirAhmadianB/scriptorium-research-agent/security)
2. Select "Report a vulnerability" to open GitHub Security Advisories
3. Describe the vulnerability in detail

### Fallback Contact
If you cannot access GitHub's private vulnerability reporting, please email:
h.a.baghbaderani@gmail.com

Include:
- A clear description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact

### Response Timeline
This is a solo-maintained project. Response times are best-effort and not backed by an SLA, but all security reports will be acknowledged as promptly as possible. We take all reports seriously and will work to resolve confirmed vulnerabilities quickly.
